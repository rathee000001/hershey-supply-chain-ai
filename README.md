# Hershey Supply Chain AI

Evidence-first local AI pipeline for the HERSHEY'S Milk Chocolate Candy Bar 1.55 oz U.S. market.

Build order:
1. Raw source collection
2. Local document ingestion
3. Level 1 parsed document artifacts
4. Evidence blobs
5. Level 2 audited supplier/cost/display blobs
6. Node-edge supply chain architecture
7. Interactive supply chain website

No supplier relationship is treated as confirmed unless supported by evidence.
